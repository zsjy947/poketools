# PokéTools 迭代规划（四期）

> 本文档是**当前迭代的总规划**。一期~三期的交付设计见 `docs/DESIGN.md`（由原三份 DESIGN 文档合并，见 P1-1），
> 数据缺口见 `docs/DATA-GAPS.md`，用户手册见 `docs/USER-MANUAL.md`。历史需求原文存档于本文档第四节与本文件的 git 历史。

## 一、背景与现状

三期交付后，项目已具备：按游戏组织的功能入口（剑盾 / BDSP / 传说 阿尔宙斯 / 朱紫 / 传说 Z-A）、
地区图鉴捕捉追踪、招式表 + 生蛋链、努力值查询、三明治 / 甜甜圈 / 咖喱特化页、
经 @smogon/calc 逐 roll 校准的伤害计算器、官方绘图 1347 张。

本轮需求为 2026-09 用户反馈 13 条，聚焦四件事：
**资产升级**（属性图标、三明治图、游戏图标）、**图鉴详情页重设计**（含形态拆分与翻页体验）、
**伤害计算器推倒重建**（效仿 pokestats.top/calc）、**架构与打包规范化**（release 目录 + 代码结构）。

`USER-MANUAL.md`、`DATA-GAPS.md`、`SELF-ITERATION.md` 保留不动（非设计文档）。

**验收**：docs 下设计文档仅剩 `DESIGN.md`；AGENTS.md 引用无死链；SELF-ITERATION 中对旧文档的勘误要点（Z-A 公式接入、灼伤）已并入 DESIGN.md 正文。

**现状**：详情页信息齐全但排布紧凑、偏列表化；种族值与能力值计算虽在同一 block 但割裂成左右两块；

### P2-4 图鉴翻页平滑化

**现状**：详情页点「上一只/下一只」整页闪白 + 方框展开动画。根因：`app.js:43` 以**整个 hash** 作

消除 Element Plus 折叠/展开动画感；滚动位置平滑回顶。

**验收**：连续点击「下一只」无白屏闪烁与方框展开动画，过渡平滑。

**验收**：侧栏无档案 UI；捕捉勾选与自定义食谱功能正常（存默认档案）。

### P3-3 甜甜圈页

**规则依据**（52poke「甜甜圈」页已核实）：甜甜圈由**黄油（固定基底）+ 树果**制作；黄油随剧情解锁
（密阿雷黄油 → 异次元黄油，玩家不可选），只影响树果上限——**3 个起步，最多 8 个**；
风味由树果五维（甜/辣/酸/苦/鲜）求和，阈值 120/240/350/700/960 定★；仅 3★ 及以上产生风味力量，
由数值最大的 1~2 项风味决定力量类型。

**方案**：
1. 录入配方：树果改**可搜索多选 el-select，前端校验 3 ≤ 数量 ≤ 8**；**删除黄油输入**，页面仅保留黄油剧情说明文字。
2. 新增风味预览：所选树果五维求和 → 计算风味级别★ → 达 3★ 时按最大 1~2 风味映射 `flavor_powers` 表给出预期风味力量
   （数据表 `berries` / `flavor_powers` 已具备，纯前端计算）。

**验收**：树果少于 3 个无法提交；无黄油输入；选满树果即时显示★与预期力量。

### P4 伤害计算器重构（重点）

**范围决策（已确认）**：

- 计算器为**完全独立入口**（`#/calc`），**不随侧栏所选游戏联动**；招式/宝可梦数据源用 `learnsets_all` 全世代并集。
- **超级进化 / Z招式 / 极巨化 / 太晶化四个点亮图标互斥**（同侧同时只能点亮一个），点亮即生效。

**P4-1 模式精简**：`damage.py` 删除 `pla`/`za` 公式分支与 `style` 参数；`calc.py` 清理对应 opt；
前端删公式 radio；相关测试更新；`tools/calib` 保留 modern 校准。
