# USER-MANUAL —— 使用手册

## 启动

| 方式 | 命令 | 说明 |
|---|---|---|
| 开发 | `python -m app.main` | 浏览器打开 http://127.0.0.1:8734 |
| 桌面 | `pythonw launcher.pyw` | pywebview 原生窗口（需 WebView2） |
| 打包 | `./build_exe.bat` | 生成 Poketools.exe（精灵球图标），与 data 文件夹放一起双击 |

数据/图片重建顺序：`python scripts/build_db.py` → `python scripts/scrape_52poke.py` → `python scripts/fetch_sprites.py`（首次需 `git clone --depth 1 https://github.com/PokeAPI/pokeapi data/raw/pokeapi`）。

## 界面结构

```
游戏中心（首页）
 ├─ 剑／盾 ──── 地区图鉴 · 努力值查询 · 咖喱图鉴
 ├─ 晶灿钻石／明亮珍珠 ─ 地区图鉴 · 努力值查询
 ├─ 传说 阿尔宙斯 ─ 地区图鉴 · 努力值查询
 ├─ 朱／紫 ──── 地区图鉴 · 努力值查询 · 三明治食谱
 └─ 传说 Z-A ── 地区图鉴 · 努力值查询 · 甜甜圈工房
伤害计算器（全局）
```

- 左侧边栏：进入某个游戏后自动显示该游戏的功能子菜单；伤害计算器为全局独立入口。
- 详情页只展示**当前入口游戏**的图鉴介绍、获取方式与招式表。

## 图鉴追踪

1. 游戏中心点游戏卡片 → 图鉴。
2. 图鉴 tab 之间切换（右上环形进度 = 本图鉴完成度）。
3. **捕捉标记**：卡片右上角的精灵球按钮点击切换（红球=已捕捉）；卡片本体点击进入详情。
4. 筛选：全部/已捕捉/未捕捉、属性、名称或编号搜索；「反选未捕捉」把当前筛选下未捕捉的全部标记为已捕捉。

## 宝可梦详情

- **头部**：官方绘图、属性、特性（★=隐藏特性）、蛋组、身高体重、击倒努力值。
- **进化链**：点击任意节点跳转；箭头下方是进化条件（等级/道具/亲密度等）。
- **图鉴介绍 / 获取方式**：仅当前游戏；获取方式按「本体 / DLC / 版本独占」分组（如「朱／紫·零之秘宝」）。
- **种族值与能力值计算**：调整等级/性格/努力值/个体值实时算出能力值（公式与游戏一致）。
- **属性相性（防守）**：按 ×4/×2/×1/×½/×¼/×0 分组，切换单形态/多属性形态自动重算。
- **招式表**：按游戏分类（朱紫=升级/学习器/蛋/教授；Z-A=升级(含精通等级)/学习器；阿尔宙斯=升级/教授）。
  - 学习器行展开看获取地点与制作材料；蛋招式可「计算繁殖链」（最短路径、全部最短路线）。

## 努力值查询

游戏入口内使用，只列出当前游戏图鉴中的宝可梦；点击行进入该宝可梦详情页。

## 三明治食谱（朱／紫）

- **食谱列表**：按食力/属性/等级筛选，编号/效果/等级排序。
- **食材与调味料**：名称、说明、获得方式（商店）、价格。
- **我的食谱**：自由模式配方录入（效果、食材/调味料可搜索多选，可起名），可删除。

## 甜甜圈工房（传说 Z-A）

- **特殊配方**：5 种特殊甜甜圈（风味数值/食材/风味力量/失控超级进化对象/扭洞位置）。
- **基础甜甜圈**：6 种口味与说明。
- **树果效果**：66 种树果的 甜/辣/酸/苦/鲜 数值、增幅等级、饱腹能量。
- **风味力量**：全部风味力量的效果与三档等级说明。
- **我的配方**：树果可搜索多选（3~8 个），实时预览风味级别与预期力量；黄油随剧情固定无需选择。

## 咖喱图鉴（剑／盾）

151 种咖喱的图鉴与介绍；可按名称/关键食材搜索，按关键食材筛选；每组第一张卡显示成品图；页首有等级与奖励说明。

## 伤害计算器

- 三套公式：现代（剑盾/朱紫）、Z-A、阿尔宙斯。
- 双方均可配置：形态（含超级进化快捷按钮）、等级、性格、努力值/个体值、能力等级、特性（自动带出该形态自身特性并置顶）、道具（分组下拉，注明是否参与计算）、**太晶属性**、极巨化。
- 攻击方可勾选 **Z招式 / 极巨化**：按官方威力换算表自动换算（互斥）。
- 中间列：招式（全世代并集）、威力覆盖、天气、光墙/反射壁、会心、灼伤、阿尔宙斯风格。
- 结果：16 档随机伤害、伤害占比、是否确一；可「对比某一方全部形态」排序。
