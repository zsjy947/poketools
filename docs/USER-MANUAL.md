# USER-MANUAL —— 使用手册

## 启动

| 方式 | 命令 | 说明 |
|---|---|---|
| 开发 | `python -m app.main` | 浏览器打开 http://127.0.0.1:8734 |
| 桌面 | `pythonw launcher.pyw` | pywebview 原生窗口（需 WebView2） |
| 打包 | `./build_exe.bat` | 生成 `release/poketools/Poketools.exe`，与 data 文件夹放一起双击 |

数据/图片重建：`build_db.py → build_z_moves.py → build_db.py → scrape_52poke.py → fetch_sprites.py → fetch_calc_assets.py → fetch_feature_images.py`
（首次需 `git clone --depth 1 https://github.com/PokeAPI/pokeapi data/raw/pokeapi`；详见 ARCHITECTURE §2）。

## 界面结构

```
游戏中心（首页）
 ├─ 剑／盾 ──── 地区图鉴 · 努力值查询 · 咖喱图鉴
 ├─ 晶灿钻石／明亮珍珠 ─ 地区图鉴 · 努力值查询
 ├─ 传说 阿尔宙斯 ─ 地区图鉴 · 努力值查询
 ├─ 朱／紫 ──── 地区图鉴 · 努力值查询 · 三明治食谱
 └─ 传说 Z-A ── 地区图鉴 · 努力值查询 · 甜甜圈工房
伤害计算器（全局）
```

- 左侧边栏：进入某个游戏后自动显示该游戏的功能子菜单；伤害计算器为全局独立入口。
- 详情页只展示**当前入口游戏**的图鉴介绍、获取方式与招式表；形态列表也按该游戏过滤。

## 图鉴追踪

1. 游戏中心点游戏卡片 → 图鉴；图鉴 tab 之间切换（右上环形进度 = 本图鉴完成度）。
2. **捕捉标记**：卡片右上角的精灵球（红白填充球=已捕捉，灰描边球=未捕捉），卡片本身**不变色**；
   卡片点击进入详情。
3. **标记模式**：页头开关打开后，点击整张卡片直接切换捕捉（不进详情）。
4. **批量操作**（下拉菜单，每项需确认）：标记当前筛选 / 清除当前筛选标记 / 标记整本图鉴 / 清空整本图鉴。
5. **同游戏自动同步**：在任一图鉴标记，同游戏其他图鉴（本体↔DLC）的同一宝可梦自动对齐；跨游戏不传播。
6. 筛选：全部/已捕捉/未捕捉、属性、名称或编号搜索。
7. 图鉴卡片默认显示该图鉴的代表形态（如洗翠图鉴的卡蒂狗显示洗翠样子、北上乡月月熊显示血月样子）。

## 宝可梦详情

- **头部**：官方绘图、属性、分类、**体型**、蛋组、捕获率、身高体重、击倒努力值。
- **特性**（阿尔宙斯与传说 Z-A 无此栏）：展开卡显示效果与说明，多点补充折叠在「详细介绍」。
- **进化链**：地区形态按分支整条渲染（如伽勒尔喵喵→喵头目，条件标注「在伽勒尔地区」）。
- **图鉴介绍 / 获取方式**：仅当前游戏；获取方式随所选形态过滤（普通喵喵不显示喵头目的获取行）。
- **属性相性**：防守面按倍率悬挂分组；攻击面带 ⚔ 标记；属性徽章定宽不换行错位。
- **种族值与能力值**：等级/性格/努力值/个体值实时计算；进度条统一单色。
- **形态条**：默认形态不带文字标注；选中其他形态后可「还原默认形态」。
- **招式表**：剑盾/BDSP=升级（进化招式置顶标「进化」）/学习器/蛋/教授；**朱紫=升级/进化&回忆（标「进化」「回忆」）/学习器/蛋**；
  Z-A=升级（含精通等级）/学习器。学习器行展开看获取地点与制作材料；蛋招式可「计算繁殖链」。

## 努力值查询

游戏入口内使用，只列当前游戏图鉴中的宝可梦；表格撑满页面，**野外地点列**列出该作自然出现位置
（超 3 条折叠 +N，悬停看全部；单版本独占与 DLC 地点带彩色标签）；点击行进入详情。

## 三明治食谱（朱／紫）

- 食谱列表：食力/属性/等级筛选与排序；食材调味料表含获取方式。
- **我的食谱**：效果 + 食材/调味料**逐条添加并选择数量**（「生菜 ×2」），可删除。

## 甜甜圈工房（传说 Z-A）

- 特殊配方/基础甜甜圈/树果效果/风味力量四表。
- **我的配方**：树果逐条添加、可同种多个，**合计 3~8 个**实时校验；风味预览按数量加权。

## 咖喱图鉴（剑／盾）

151 种咖喱全部显示所属组共享成品图；可按名称/关键食材搜索筛选。

## 伤害计算器

- 现代公式（与 @smogon/calc 逐 roll 校准），默认**双打**（场地区中栏可切单打；双打下扩散招式 ×0.75、屏幕削弱减弱）。
- 切出再进入**零加载感**：视图常驻保留全部状态，不重复请求。
- **对战场**：左右摘要卡顶部为**太晶化/极巨化图标标记**（点击点亮；太晶图标随编辑面板所选太晶属性切换，含星晶）；
  下方**竖列 4 招式按钮**——每招左侧是 **Z 纯晶图标**（点击点亮 → 自动装备对应纯晶、招式变 Z 招式；
  一场只能点亮一个；手动改道具即解除）。点任一招式即以该侧为攻击方计算。
  **招式显示官方名**：极巨化时按属性显示极巨招式名（如「极巨龙骑」，变化招显示「极巨防壁」）；
  超极巨形态属性命中显示超极巨招式名（如「超极巨地狱灭焰」）；Z 招式显示专属/泛用 Z 招式名
  （如「认真起来大爆击」「究极巨龙震天地」；帽子皮卡丘+十万伏特=「千万伏特」）。
- **结果条**：完整中文描述 + 16 档随机伤害 + KO 表述（「确定 N 回合击倒」「P% N 回合内击倒」）。
- **编辑面板**（每侧，标题「左侧编辑/右侧编辑 · 当前宝可梦」）：宝可梦/**形态（超级进化·超极巨化在此选择**，
  选 mega 自动锁进化石道具；烈空座校验携带画龙点睛）→ 特性（自身 + 全量）→ 太晶属性 →
  道具（全量可搜索带图标）→ 4 招式（威力自动带出，变动威力招才出现输入框）→ 种族值（只读）→
  努力值滑杆（含剩余）→ 性格 → 攻防能力升降 ±6 → 等级。
- **机制互斥**：超级进化/超极巨化与 太晶/Z 标记同侧互斥（点亮被阻止并提示；极巨化 HP×2 显示）；
  超极巨化本身即极巨化——gmax 形态与极巨标记共存合法。
- **场地与状态区**（三栏＝左宝可梦状态 / 场地全局 / 右宝可梦状态，≤1080px 单列降级；对齐参考站布局）：
  - 中栏 7 行：单打|双打（默认双打）→ 晴天·雨天·沙暴·雪天 → 大日照·大雨·乱流 → 四场地 →
    气场破坏·妖精气场·暗黑气场 → 灾祸四件套（两行按钮：招式名 + (-防御) 等效果标识）→ 重力·魔法空间·奇妙空间。
  - 左右两列各 8 行**完全对称**（同一份配置渲染，左右固定绑定左右宝可梦，不随攻守换边）：
    状态异常 6（灼伤参与计算；中毒/剧毒/冰冻/睡眠/麻痹为标记展示）→ 反射壁·光墙·极光幕·友情防守 →
    击中要害（独占行）→ 帮助·钢之意志·蓄电池·能量点 → 隐形岩＋撒菱 1|2|3（连体分段）→
    寄生种子·盐淹 → 力量戏法·被识破 → 花之礼·顺风（展示）·**切换**。
  - **力量戏法**＝该侧攻击与防御实际值互换；**切换**＝换下场状态（点亮后对方用**追打**打该侧威力 ×2，
    对其他招式无影响）。
  - **气势披带**不在场地区：作为**道具**装备即自动生效（不会被满血一击秒杀）。
  钉子等进场扣减自动计入 KO 判定；点任一侧招式按钮即以该侧为攻击方计算。
