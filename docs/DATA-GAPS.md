# DATA-GAPS —— 数据完整性说明

> 依据「信息完全校验」要求：抓取/计算无法完全覆盖的数据在此逐项说明。
> 前端对缺失数据一律显示「待补充」，绝不编造。重建数据后请重读本文件核对是否已过期。

## 1. Z-A 学习集（94 / 364 种无数据）

- **现状**：Z-A 图鉴 364 种中，269 种的学习集已从 52poke `{种类}/第九世代招式表` 子页抓取（升级含精通等级 + TM001-107）。
- **缺口**：94 种（如超音蝠、凯西、腕力等未在朱紫登场的种类）没有第九世代招式表子页——52poke 尚未收录其 Z-A 招式数据。
- **PokeAPI 也没有**：vg30/31 无 pokemon_moves 数据；vg32 是 Pokémon Champions（对战游戏）的 train 数据，与 Z-A 无关，已剔除。
- **影响**：这些种类的 Z-A 招式页显示空表。名单见 `data/curated/TODO.json` 的 `za_learnset_issues`。

## 2. Z-A 招式学习器获取方式

- Z-A 的 TM001-107 编号与招式映射已入库（PokeAPI machines vg30，与 52poke 各种类页一致）。
- 但 **52poke 无 Z-A TM 获取地点专页**（招式学习器页面的 TMtable 模板没有 locza 键），tm_how vg30 仅 1 条。
- **影响**：Z-A 招式表的学习器行展开显示「获取方式待补充」。

## 3. 朱紫 TM 获取文本（31 / 229 缺失）

- TM172~201 与 TM218 共 31 个学习器在 52poke 的 loc9 字段为空（这些是校内商店/LP 兑换为主的学习器，wiki 未整理地点）。
- **影响**：展开这些 TM 行显示「获取方式待补充」；编号与招式映射本身完整。

## 4. BDSP

- **图鉴描述**：52poke `bdspdex` 字段覆盖 338 种，神奥图鉴 210 种内若有缺失显示「待补充」。
- **捕捉地点中文名**：捕捉方式来自 52poke（中文），PokeAPI 无 BDSP encounters，无英文兜底问题。
- **TM073** 曾因繁体「電磁波」匹配失败，已用别名表修复（TM001-100 全部入库）。

## 5. 咖喱图鉴图片

- 151 种咖喱中，每组（按关键食材分组）第一张卡显示「玩家食用」图；小份/中份/大份图片未入库（数量大、信息重复）。
- 「创意咖喱」等个别组若 wiki 无对应图片则不显示。

## 6. 宝可梦图片

- `data/sprites/{form_id}.png` 三级回退：**官方绘图 → HOME 类3D → 像素图**（PokeAPI sprites 仓库）。
- 少数活动/特殊形态（如部分帽子皮卡丘）三级均 404 时卡片图片隐藏（不显示占位叉）。
- 官方绘图统一用 Pillow 缩到 256px 以控制体积；原图 475px 版本可自行改 `scripts/fetch_sprites.py` 的 `MAX_SIZE`。

## 7. 属性图标

- 四期起采用 **52poke 雪碧图**（`assets/type_sprite.webp`，MST_SV 50×1050 = 21 格：
  18 属性 + 物理/特殊/变化），CSS 显示 16px/格，随 dist 提交离线可用。
- 星晶等无对应图标格的标记退化为纯色胶囊。

## 8. 伤害计算器近似项

| 项目 | 处理 | 说明 |
|---|---|---|
| Z 招式威力 | 官方换算表（区间）+ 9 个常见特例 | 个别招式特例未全部收录；固定伤害类按 100 |
| 极巨招式威力 | 官方换算表（含格斗/毒独立档） | 一击必杀类按 130；连续招式按 3 次计算未实现（需按招式特判） |

| 防守向道具 | 突击背心/进化奇石已建模（特防或双防 ×1.5） | 吃剩的东西/气势披带不参与伤害数值，仅列出 |
| 能力等级/天气/光墙反射壁/会心/灼伤 | 已建模 | 其余特性（引火等免疫类）只影响「相性归零」未自动化，可用相性覆盖或 0 威力模拟 |
| 阿尔宙斯/Z-A 公式 | 已随四期 P4-1 移除 | 只保留现代公式（@smogon/calc 逐 roll 校准） |

| 电气/精神/薄雾场地 | 不影响伤害数值，仅作对局标记 | 其效果（防睡眠/防先制等）超出单次计算范围 |

## 9. 三明治食材获取方式

- 35 种食材的「获得方式」来自各自道具页的 `道具地点` 模板（如「从火户面包店或全都友超市购买」），全部抓到。
- 调味料 18 种的获取地点与价格来自 `野餐道具` 页表格，完整。

## 10. 进化条件

- 条件来自 PokeAPI `pokemon_evolution`（等级/道具/亲密度/时间/地点/招式/倒置主机等），中文拼装。
- 少数机制未覆盖：`relative_physical_stats`（攻击与防御关系，如霸王花系未用）、`party_species`（队伍内有特定宝可梦）、`near_special_rock` 等冷门条件显示为基础触发方式。
- 伊布等多分支家族按分支树展示。
