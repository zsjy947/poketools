## 已确认决策

| 决策点 | 结论 |
|---|---|
| 单打/双打切换 | **纳入**（场地区全局切换，默认双打）；双打下扩散招式伤害 ×0.75，帮助/蓄电池/能量点等友方辅助在双打语义下生效 |
| 机制归属 | 太晶化/极巨化 = 顶部点亮标记；Z 招式 = 每招一个点亮标记；超级进化/超极巨化 = 编辑面板形态选择（非标记）；除裂空座外选超级形态自动锁定对应进化石道具，裂空座改为校验「画龙点睛」 |
| 太晶图标随属性变 | 编辑面板选择太晶属性，顶部太晶化图标随之切换（52poke `太晶 {属性} icon.png` 18 属性 + 星晶各一张） |
| Z 纯晶与专属 Z | 使用 Z 招式必须携带对应 Z 纯晶道具：点亮 Z 标记自动装备该招属性的泛用 Z 纯晶；若（宝可梦+原始招式）命中专属 Z 映射则改装备专属 Z 纯晶、按专属 Z 招式（固定威力/分类）计算 |
| 太晶相性判定 | 伤害与相性一律按防守方**太晶后**属性计算——太晶属性替换原两防御属性（原属性弱点/抵抗/免疫失效），星晶防守=全中性 |
| 星晶太晶 | 太晶属性下拉含「星晶」；攻击方星晶=原属性 STAB 保留 ×2 + 该属性首次攻击招式 ×1.2（对齐 @smogon/calc） |
| 计算器无游戏上下文 | 伤害计算器为全局入口，特性/道具选择**不按游戏隐藏**（阿尔宙斯与 Z-A 形态的 PokeAPI 特性数据仍可选）；「LA/Z-A 隐藏特性栏」仅指图鉴详情页，见 UPDATE-PLAN M2 |
| KO 表述 | 「几回合击倒」式（如「确定 2 回合击倒」「84% 2 回合内击倒」），禁止「无法 N 回合击倒」 |
| 展示哲学 | 全量展示：全量道具/全量特性/全量场地状态，无影响的照常列出，不加「（不参与计算）」类小字 |

14. **KO 回合泛化**：`koProb(n)` n=1..4，按 16 rolls 伤害分布卷积/枚举（16⁴=65536 可控），输出 `guaranteed_turns`（P=100% 最小 n）与 `probs[1..4]`；配合进场 HP 扣减先扣后算。前端文案：「确定 N 回合击倒」/「P% N 回合内击倒 · 保证 M 回合」。
15. **星晶（Stellar）太晶判定**：太晶属性下拉 18 属性外增「星晶」（图标 `太晶 星晶 icon.png` 已核实有源）；**防守方**星晶=对全部属性 ×1 中性（不继承任何弱点/抵抗/免疫）；**攻击方**星晶=原属性 STAB 保留 ×2（同太晶规则）+ 所用招式属性命中「首次攻击招式」时威力 ×1.2（4915/4096 分数；单次计算按该属性当次为首次处理，UI 注明每属性限一次）；`SPECIAL_MOVES` 增 `tera-starstorm`（星晶爆发由太乐巴戈斯使用时按星晶属性判定；星晶招式对太晶化目标的相性特殊规则以 @smogon/calc 为准对拍）。
16. **防守方太晶相性判定（明确为必须项）**：招式威力与属性相性一律按防守方**太晶后**属性计算——太晶属性替换原两防御属性，相性只看太晶单属性（原属性弱点/抵抗/免疫全部失效，特性类免疫另行判定）；现实现已含防守太晶（test_damage「太晶 STAB 与防守太晶」），此条定为不可回退的判定项，calib 增「太晶后弱点变化 / 原免疫消失」两案例。
